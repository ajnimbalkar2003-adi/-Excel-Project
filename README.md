# HR Attrition Analysis Dashboard

## Project Overview

This project focuses on analyzing HR data to understand employee attrition and workforce trends using Microsoft Excel.

## Dashboard Features

* Employee Attrition by Department
* Average Performance Rating
* Employee Tenure Analysis
* Department-wise Attrition
* Employee Satisfaction Analysis
* Work-Life Balance
* Job Involvement
* Overtime Rate and Attrition Rate
* Gender-wise Employee Distribution

## Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Visualization

## Key Learning

Through this project, I improved my skills in Excel, data analysis, dashboard creation, and data visualization.
